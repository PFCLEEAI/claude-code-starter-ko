이 페이지 사용법

3줄 요약
  • 수업에서 "다들 아시죠?" 하고 넘어가는 기초를 한곳에 모아 둔 페이지예요.
  • 처음부터 읽어도 되고, 모르는 단어가 나오면 위쪽 검색창에 쳐서 관련 제목·명령어·용어를 찾아봐도 돼요.
  • 첫 주에는 아래 "공부 순서"대로 하루 30분씩만 읽어 보세요.

부트캠프 둘째 날부터 Claude Code가 바로 나와요. 그런데 터미널, 컨텍스트, 토큰 같은 말이 낯설면 수업 내용이 귀에 잘 안 들어오죠.

이 페이지는 그 빈칸을 채우려고 만들었어요. 개발 경험이 없어도 읽을 수 있게 비유와 그림 위주로 썼어요.

이렇게 쓰면 편해요

🔍 검색창

검색창에 "컨텍스트", "/compact"처럼 치면 관련 제목·명령어·용어 목록이 떠요. 하나를 누르면 그 자리로 가요.

📑 목차

목차에서 장 제목을 누르면 그 장으로 이동해요. 지금 어디쯤 읽고 있는지도 보여요.

💡 ⚠️ 📌 상자

💡는 알아 두면 편한 팁, ⚠️는 꼭 조심할 점, 📌는 덧붙이는 메모예요.

📂 더 알아보기

접혀 있는 "더 알아보기"는 궁금할 때만 펼치면 돼요. 안 읽어도 흐름은 이어져요.

🧪 예시

상황: 수업 중에 강사님이 "컨텍스트가 차면 압축돼요"라고 했는데 무슨 말인지 모르겠어요.

검색창에 입력: 컨텍스트

결과: 결과 목록에서 "컨텍스트: AI가 지금 보고 있는 모든 것"을 누르면 그 부분으로 가요. 책상 비유와 그림으로 5분 안에 감을 잡을 수 있어요.

💡 장마다 맨 위에 "3줄 요약"이 있어요. 시간이 없으면 요약만 훑고, 막히는 부분만 본문을 읽어도 괜찮아요.
📌 더 깊이 알고 싶으면 본문 곳곳의 ↗ 링크를 눌러 보세요. CC101 강의나 공식 문서로 연결돼요.

한눈에 보는 전체 지도

이 페이지는 11개 장으로 되어 있어요. 아래 지도는 0장을 빼고 01~10장이 무엇을 다루는지 보여 줘요.

🧪 예시

상황: 팀 프로젝트 회의에서 "MCP로 노션 연결하자"는 말이 나왔는데, MCP가 어느 장에 있는지 모르겠어요.

지도에서 찾기: MCP → "03 Claude Code 구성요소"
목차에서 "Claude Code 구성요소" 누르기

결과: 그 장의 "MCP: 외부 서비스와 잇는 USB-C" 부분을 읽으면 돼요. 지도는 "이 단어가 어느 장에 있지?" 할 때 쓰면 돼요.

첫 주 공부 순서

모든 장을 한 번에 읽을 필요는 없어요. 수업 진도에 맞춰 이 순서로 읽으면 부담이 적어요.

  1. 첫날 (수업 전) 01 AI 도구 지형도에서 Claude Code가 ChatGPT나 Claude 채팅과 뭐가 다른지 감을 잡아요.
  2. 둘째 날 (Claude Code 설치하는 날) 02 기초 개념에서 폴더·터미널·컨텍스트를 읽어요. 설치하다 막히면 여기부터 다시 봐요.
  3. 셋째 날 03 Claude Code 구성요소에서 CLAUDE.md 부분만 먼저 읽고, 06 명령어 총정리의 TOP 10 카드를 손에 익혀요.
  4. 넷째 날 04 프롬프트 기초를 읽고, "대구 로컬 브랜드 소개 글 써 줘" 같은 요청을 나쁜 예/좋은 예로 바꿔 써 봐요.
  5. 다섯째 날 모르는 단어는 09 용어 사전에서 찾고, 10 더 공부하기의 집 연습 루틴을 하나 골라요.
🧪 예시

상황: 넷째 날 저녁, 04장을 읽고 30분 연습을 해요. 수업 때 썼던 짧은 요청을 고쳐 써 봐요.

전: 대구 로컬 브랜드 소개 글 써 줘
후: 서문시장 수제 약과 브랜드를 20대에게 알리는
    인스타그램 소개 글을 써 줘. 3문장, 해요체,
    해시태그 5개까지.

결과: "전"은 어디에나 쓸 법한 무난한 글이 나오고, "후"는 바로 올릴 수 있는 글에 가깝게 나와요. 두 결과를 나란히 비교해 보는 게 이날 연습이에요.

💡 "프롬프트 엔지니어링", "에이전트 개념", "Git·GitHub 기초"는 수업에서 해당 주제가 나오는 주에 읽어도 충분해요.
